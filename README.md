# 入梦｜清醒梦训练

“入梦”是一份可以直接打开和分享的清醒梦训练 HTML 文件。页面、样式和交互都已打包在同一个文件中，无需安装、注册、联网或启动服务器。

## 打开与分享

1. 下载 [`入梦-清醒梦训练.html`](入梦-清醒梦训练.html) 到电脑或手机。
2. 用 Chrome、Edge 或 Safari 打开该文件。
3. 分享时直接把这个 HTML 文件发给对方；对方下载后即可在浏览器中打开。

梦境日记和练习进度保存在当前浏览器的本地存储中。分享 HTML 文件不会分享你的日记；记录也不会自动同步到其他设备。

## 怎么使用

- **今日**：查看现实检验和睡前意向。点击练习旁的“？”查看原理、步骤与注意事项；点击空方框记录完成情况。
- **梦境**：醒来后记录梦境片段，可填写日期、清晰度、感受和是否意识到自己在做梦。片段或几个词都可以。
- **回顾**：查看最近 7 天的练习次数和梦境记录。
- **设置**：选择白天或傍晚的应用内提醒，或清除当前浏览器中的全部数据。
- **完整训练计划**：在“今日”页面点击“查看完整训练计划”，了解每天的安排和四周练习重点。

## 四周练习安排

| 周次 | 练习重点 | 每天建议 |
| --- | --- | --- |
| 第 1 周 | 记住梦 | 自然醒来后花 1–3 分钟记录梦境片段；没记住也没关系。 |
| 第 2 周 | 练习觉察 | 白天选 2–3 个自然线索，停下观察环境并认真询问自己是否在做梦。 |
| 第 3 周 | 睡前意向 | 睡前回想一个梦境线索，想象自己在梦中认出它，然后自然入睡。 |
| 第 4 周 | 温和组合 | 继续记梦和日间觉察；在放松的晚上练习睡前意向，也给自己留出休息时间。 |

## 睡眠与数据

练习不保证产生清醒梦，也不是医疗建议或治疗。计划不要求半夜起床、缩短睡眠或服用任何物质。若练习影响睡眠或带来不适，请暂停。

所有记录只保存在打开文件的浏览器中。点击“设置”里的“清除本机全部练习数据”即可删除。提醒只在页面打开时生效，关闭页面后不会推送。
