# LucidDream-Trainer · 入梦清醒梦练习

面向成年初学者的清醒梦训练 MVP，使用 uni-app + Vue，首发目标为微信小程序和 H5。产品提供日间现实检验、睡前意向练习、梦境日记和进展回顾，帮助用户逐步练习梦境觉察；不承诺诱导清醒梦或控制梦境的结果。

## 功能

- 新手引导，说明练习边界和本地数据保存方式
- 今日现实检验、睡前意向练习打卡
- 两项练习的原理说明，以及分阶段的 4 周完整训练计划
- 梦境日记：新增、编辑、删除、回忆清晰度和清醒梦标记
- 最近 7 天练习回顾
- 用户自设的白天/傍晚提醒
- 清除本机全部数据

训练不用于诊断或治疗。应用不提供睡眠剥夺、夜间唤醒或药物训练。若练习影响睡眠或带来不适，请暂停。

## 本地开发

```sh
npm install
npm run dev:h5
```

微信小程序：

```sh
npm run dev:mp-weixin
```

## 离线界面预览

无需安装依赖，直接打开 `preview/index.html` 即可体验训练、日记、回顾和设置流程。该独立预览把数据保存在浏览器本地存储中；正式 H5/微信构建仍通过上面的 uni-app 命令生成。

构建：`npm run build:h5` 或 `npm run build:mp-weixin`。微信小程序发布前，请在 `src/manifest.json` 填入小程序 AppID。

## 数据与提醒

训练记录通过 uni-app 本地存储保存在设备上，无账户、云同步或服务端。可在“设置与说明”中清除。

提醒只在应用打开时工作。H5 在获得浏览器通知权限后可显示系统通知；未授权时使用应用内提示。微信小程序使用应用内提示；订阅消息需要后端和消息模板，当前未接入。提醒时间可设为 08:30、12:30、18:30 或 20:30，不会在夜间提醒。

## 项目结构

- `src/pages/index/index.vue`：主页面与核心训练流程
- `src/utils/storage.js`：本地状态读写
- `src/pages.json`、`src/manifest.json`：uni-app 页面和平台配置
