# 入梦｜清醒梦训练

“入梦”是一款帮助成年人练习梦境回忆和清醒梦觉察的小程序。它用梦境日记、白天的现实检验和睡前意向，带你按自己的节奏练习。每个人的体验不同，清醒梦不是练习的保证结果。

## 怎么开始

1. 首次打开后阅读引导，点击“开始我的练习”或“先看看再说”。不需要注册账号。
2. **早上醒来**：打开“梦境”，记录还记得的场景、人物或感受；只记下几个词也可以。
3. **白天**：在“今日”页做 2–3 次现实检验。停下来观察环境，回想自己刚才在做什么，再问自己“我现在是在做梦吗？”
4. **睡前**：用约 2–3 分钟回想一个梦境线索，想象自己在梦里发现它并意识到正在做梦，然后放下练习、自然入睡。
5. 通过“回顾”查看最近 7 天的练习与梦境记录；在“设置”中调整提醒或清除本机数据。

今日练习卡片旁的 **？** 会解释练习原理、具体步骤和注意事项。点击“查看完整训练计划”可打开完整的四周安排。

## 四周训练计划

| 阶段 | 练习重点 | 每天怎么做 |
| --- | --- | --- |
| 第 1 周：记住梦 | 建立梦境回忆习惯 | 醒来后花 1–3 分钟记下片段；没有记住也没关系。 |
| 第 2 周：练习觉察 | 认真观察，而不是机械重复 | 白天选 2–3 个自然线索，停留约 20–30 秒，观察环境并回想记忆是否连贯。 |
| 第 3 周：设定意向 | 排练在梦中发现线索 | 睡前回想一个梦、想象自己认出梦境，轻轻默念“下次做梦时，我会认出自己在做梦”，然后自然入睡。 |
| 第 4 周：温和组合 | 找到适合自己的节奏 | 继续记梦和白天觉察；放松时做睡前意向，每周可留 1–2 晚只休息。 |

现实检验单独使用的效果证据有限；睡前意向属于 MILD（记忆意向法）的简化练习，研究有一定支持，但不能保证个人效果。计划不要求半夜起床、缩短睡眠或服用任何物质。睡眠和休息始终优先；如果练习影响睡眠或让你不舒服，请暂停。

## 页面说明

- **今日**：完成现实检验和睡前意向；通过“？”了解每项练习；进入完整训练计划。
- **梦境**：新增、编辑或删除梦境日记，可记录日期、清晰度、感受和是否为清醒梦。
- **回顾**：查看最近一周的梦境记录和练习次数，不用与他人比较。
- **设置**：开启或关闭温和提醒、选择提醒时间、清除设备上的全部练习数据。

## 数据与提醒

无需注册。梦境日记和练习记录只保存在当前设备，不会同步到云端。可在“设置”中清除本机数据。

提醒时间可选 08:30、12:30、18:30 或 20:30。提醒仅在应用打开时生效；关闭应用后不会推送。H5 可在授权浏览器通知后显示系统通知；微信订阅通知尚未接入服务端。

## 直接体验

打开 [`preview/index.html`](preview/index.html) 即可体验独立的浏览器预览，无需安装依赖。梦境记录保存在该浏览器的本地存储中。

## 开发与构建

项目使用 uni-app + Vue，目标为微信小程序和 H5。

```sh
npm install
npm run dev:h5
```

微信开发工具：`npm run dev:mp-weixin`。构建命令为 `npm run build:h5` 和 `npm run build:mp-weixin`。发布微信小程序前，需在 `src/manifest.json` 配置 AppID。
